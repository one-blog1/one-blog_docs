# 5. 메인과 개별 블로그의 범위, 결정 필요 사항

개별 블로그는 이 문서의 계정·역할·게시판 모듈을 그대로 씁니다. 처음에는 오른쪽 열을 다음 문서에서 더하려 했으나, 꾸미기를 빼고는 이 문서의 요구사항으로 이미 만들어 운영 중입니다.

| 영역 | 메인블로그 (이 문서) | 개별 블로그 |
|---|---|---|
| 회원 | 가입, 로그인(소셜 로그인 포함), 탈퇴, 정보 수정 | 없음 (메인 계정 사용) |
| 블로그 | 생성, 목록, 검색, 참여 신청, 내 블로그 | 운영 중: 블로그 정보 수정, 멤버 목록·관리, 부블로그장 권한(2장, BLG-13). 남은 것: 꾸미기(테마·메뉴) |
| 게시판 | 공통 모듈, 통합 검색, 메인 피드, 공지사항, 메인 배너 | 운영 중: 블로그 안의 글·카테고리 운영(BRD-01~03), 블로그 공지, 최신순·인기순 목록(D-129) |
| 소셜 | 팔로우, 프로필, 알림, 차단·신고 | 운영 중: 블로그 안의 댓글·좋아요(BRD-06) |
| 관리 | 메인 관리자: 블로그와 블로그장 | 운영 중: 블로그장이 자기 블로그의 멤버와 글을 관리 |

세부 숫자와 규칙은 [6장](06-detailed-policies.md), 구현 방식은 [7장](07-implementation.md), 결정 이유는 [8장](08-decision-log.md)에 있습니다.
