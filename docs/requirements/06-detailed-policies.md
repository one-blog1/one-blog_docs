# 6. 세부 정책

기능 요구사항을 코드로 옮길 때 필요한 숫자와 규칙입니다. 상태가 **확정**인 항목은 그대로 구현하고, **보류**인 항목은 팀에서 더 정해야 합니다. 팀에서 정한 것은 상태를 확정으로 바꾸고, 추천안과 다르게 정한 것은 추천안 칸을 고쳐 주세요.

## 6.1 검색

| 항목 | 추천안 | 이유 | 상태 |
|---|---|---|---|
| 검색어 길이 | 2~20자 | ngram이 2글자 단위라 1글자는 검색이 안 됨 | 확정 |
| 정렬 | 관련도순(기본), 최신순, 인기순 / 분류바(관련도, 최신, 인기) | 검색은 관련도가 기본이고, 최신순은 선택 | 확정 |
| 결과에서 제외 | 비공개 블로그(공백으로 표시), 숨김·삭제 글, 내가 차단한 회원의 글 | 검색으로 비공개 내용이 새지 않게 | 확정 |
| 부가 기능 | 1차: 최근 검색어(본인만, 최대 10개, x 개별 삭제·전체 삭제 기능) | 자동완성은 검색 로그 저장과 집계가 따로 필요 | 확정 |

| 위치 정보 | 업로드할 때 EXIF(GPS 등) 제거 | 사진에 집 위치가 남아 있을 수 있음 | 확정 |
| 썸네일 | 목록용 썸네일을 따로 만들지 않고 원본을 CSS로 줄여 표시 (1차). 목록 오른쪽에 정사각형(PC 120px, 휴대폰 88px). 본문에서 처음 나오는 사진·영상 링크 중 첫 번째가 영상 링크(유튜브·치지직·SOOP)면 그 썸네일을 서버가 글 저장 뒤 한 번 받아 우리 서버에 두고(files.purpose=VIDEO_THUMB, 2MB 이하 사진만, 위치 정보 제거) "▶ YouTube"처럼 표시. SNS 미리보기(og:image)도 같은 사진 (D-128) | 구현이 간단함. 읽는 사람의 IP가 영상 사이트로 가지 않고 보안 헤더(img-src 'self')를 그대로 둠 | 확정 |
| 글 삭제 시 | "글을 정말 삭제하시겠습니까?" 확인 버튼 | | 확정 |

| 블로그 주소 예약어 | main, admin, api, login, signup, search 등 사용 불가 | 사이트 주소와 겹치면 페이지가 안 열림 | 확정 |

| 좋아요·팔로우·구독 | 한 번만. 다시 누르면 취소 (트래픽 제한 걸기) | DB UNIQUE가 중복을 막음 | 확정 |

## 6.8 메인 배너

| 항목 | 추천안 | 이유 | 상태 |
|---|---|---|---|
| 위치 | 메인 "메인 피드" 탭 맨 위(인사말 "오늘은 어떤 이야기를 읽어 볼까요?" 대신), "내 블로그" 탭 맨 위(배너 → 내 블로그 목록 → 새 글). 참여 신청 탭에는 없음 | 처음 보이는 자리라 추천 글·광고가 눈에 띔. 인사말과 배너가 같이 있으면 글이 너무 아래로 밀림 | 확정 |
| 내 블로그 목록 | 배너 아래로 옮기고 블로그 그림을 60px 정사각형(예전 카드의 약 1/6)으로 줄임. 그림 아래 이름 한 줄(길면 …), 맨 끝 "+ 만들기", 많으면 옆으로 밀어 봄 | 배너가 들어가도 새 글이 너무 내려가지 않게 | 확정 |
| 넘김 | 5초마다 다음 장. 마우스·키보드가 올라가면 멈추고 멈춤·이전·다음·점 단추. 기기의 "움직임 줄이기"가 켜져 있으면 자동으로 넘기지 않음 | 자동으로 움직이는 내용은 멈출 수 있어야 함(WCAG 2.2.2) | 확정 |
| 인기 글 | 최근 7일 글 중 썸네일(첫 사진 또는 영상 썸네일)이 있는 글을 좋아요 많은 순(같으면 조회수, 최신)으로 3개. 좋아요가 없어도 개수를 채움(D-133). 범위는 메인 피드 인기 글과 같음(전체 공개 블로그의 공개 글, 차단한 회원의 글 제외). 관리자가 개수 0~5(0이면 끔)와 기간 1·7·30일을 고름 | 큰 사진 배너라 사진 없는 글은 빼고, 오래된 글이 계속 남지 않게 기간을 둠. 글이 적을 때 정한 개수가 비지 않게 | 확정 |
| 인기 글 표시 | 사진은 글 썸네일, 제목은 글 제목, 작은 글씨는 블로그 이름 · 좋아요 수, 표시는 "이번 주 인기"(1일은 "오늘 인기", 30일은 "이번 달 인기") | 관리자가 손대지 않아도 채워짐 | 확정 |
| 새 블로그·인기 블로그 | 자동. 새 블로그는 최근 30일에 만든 전체 공개 블로그 최신순 2개, 인기 블로그는 최근 30일에 새로 참여한 멤버(블로그장 제외)가 많은 순(같으면 전체 멤버 수) 2개. 새 블로그로 나온 블로그는 인기 블로그에서 뺌. 관리자가 종류마다 개수 0~5·기간 1·7·30일을 고름. 사진은 대표 이미지(없으면 블로그 색과 첫 글자), 제목은 블로그 이름, 작은 글씨는 멤버 수 · 소개 앞부분 (D-133) | 블로그를 알릴 자리. 숨김·폐쇄·비공개 블로그는 메인 목록처럼 뺌 | 확정 |
| 광고·공지·이벤트 | 관리자가 종류(광고·공지·이벤트)·사진·제목(1~100자)·작은 글씨(100자까지)·링크·노출 여부·순서를 넣음. 링크는 `https://`·`http://` 주소 또는 `/`로 시작하는 우리 사이트 주소만. 노출을 켠 것 중 순서대로 8개까지. 종류 이름을 늘 표시하고 광고만 초록. 바깥 주소는 새 창(광고는 rel="sponsored" 추가) (D-133) | 광고임을 알 수 있어야 하고, javascript: 같은 주소를 막음 | 확정 |
| 순서 | 종류를 하나씩 번갈아: 인기 글 → 관리자 배너(관리자가 정한 순서) → 새 블로그 → 인기 블로그 → 인기 글 2 → … 남은 것은 뒤에 (D-133) | 한쪽만 몰리지 않게 | 확정 |
| 없을 때 | 보여줄 것이 없으면 배너 자리를 숨김. 사진이 없거나 불러오지 못하면 인기 글·블로그 배너는 그 블로그 색과 첫 글자, 관리자 배너는 어두운 바탕. 관리자 화면은 종류마다 고른 개수보다 적게 나가면 그 이유(조건에 맞는 것이 n개)를 보여 줌 | 빈 상자를 보이지 않게, 개수가 왜 적은지 알 수 있게 | 확정 |
