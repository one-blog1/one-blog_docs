# One Blog 0.16

사이트 디자인을 에디토리얼로 새로 잡고, 글 목록에 미리보기·썸네일(영상 포함)을 붙이고, 블로그 글을 카테고리마다 최신순·인기순으로 보고, 어디서나 글을 쓸 수 있게 한 버전입니다 (2026-10-13).

- 코드: [one-blog1/one_blog](https://github.com/one-blog1/one_blog) main `4f1b820` (처음 배포 때 붙은 태그 `v0.16`은 `f02ddcd`. 같은 0.16으로 다시 배포함)
- 요구사항 기준: BRD-01·02·03, 6.3, SEC-08, 결정 D-89·D-104·D-125·D-127·D-128·D-129·D-130·D-131, 기능 명세 021(글 안 영상 재생), 024(글 목록 새 모양·영상 썸네일, 블로그 글 최신순·인기순)

## 기능·화면

**새 디자인: 에디토리얼** (D-131)
- 흰 바탕에 상자 대신 여백과 가는 선(밝은 화면 `#c4c7cc`), 제목은 명조 Noto Serif KR 700(서버에 직접 둠), 본문 IBM Plex Sans KR
- 로고 "one blog." (끝의 점만 초록), 강조색은 짙은 초록 하나(`#2f6f5e`). 노랑 강조와 Jua 글꼴은 뺌
- 선택된 탭·정렬·페이지는 굵은 글씨와 밑줄, 버튼·입력칸은 6px 모서리, 블로그 이름표 색은 차분한 톤
- 메인 공지 줄은 상단 바로 아래 띠(상단 선이 공지 위 구분선)
- 어두운 화면은 같은 규칙에 색만 바꿈, 확인 창(모달)은 자체 바탕
- 네 가지 시안을 디자인 캔버스로 비교해 고름

**상단 글쓰기** (D-130)
- 로그인한 회원은 모든 화면 위에 [글쓰기]. 블로그가 하나면 바로 그 블로그 글쓰기, 여럿이면 "어느 블로그에 쓸까요?" 목록(마지막에 쓴 블로그가 위), 없으면 블로그 만들기
- 글쓰기 제목은 "○○에 글쓰기", 카테고리는 글쓰기 화면에서 고름. 블로그 안 [글쓰기]는 보던 카테고리를 미리 골라 둠

**글 목록 새 모양** (024, D-128)
- 블로그·메인 "내 블로그의 새 글"·메인 피드·검색·태그 목록 한 줄: 작성자 사진·닉네임·날짜, 명조 제목, 본문 앞부분 2줄, 블로그 이름·카테고리(초록)와 좋아요·댓글·조회 수, 오른쪽 썸네일(PC 160×120, 휴대폰 88px)
- 블로그 공지 줄은 예전처럼 제목과 정보 한 줄
- 목록 응답에 `excerpt`(본문 앞 160자, 재생기 글자 빠짐), `authorImageUrl`, `thumbnailVideo`(youtube·chzzk·soop) 추가

**영상 썸네일** (024, D-128)
- 본문에서 처음 나오는 사진·영상 링크 중 첫 번째가 영상이면, 글을 저장한 뒤 서버가 그 썸네일을 한 번 받아 `files`(purpose `VIDEO_THUMB`)로 글에 연결. 목록 썸네일과 SNS 미리보기(og:image)에 씀. 썸네일에 "▶ YouTube"·"▶ 치지직"·"▶ SOOP" 표시
- 같은 영상이면 다시 받지 않고, 영상이 바뀌거나 빠지거나 글을 지우면 예전 썸네일은 30일 보관 뒤 삭제
- 유튜브는 `i.ytimg.com/vi/{번호}/mqdefault.jpg`, 치지직·SOOP은 공식이 아닌 API. 받지 못하면 썸네일 없이 둠(글 저장에는 영향 없음)
- ERD v21, `V20__add_video_thumb_file_purpose.sql`
- 테스트 `VideoThumbnailIntegrationTest`, `HttpVideoThumbnailFetcherTest`, `VideoEmbedTest`

**블로그 글 최신순·인기순** (024, D-129)
- 블로그 화면 카테고리 줄 오른쪽 끝에 작은 글자 "• 최신순 • 인기순"(고른 쪽은 빨간 점). 고른 카테고리(전체 포함) 안에서 정렬, 카테고리를 바꿔도 정렬 유지. 카테고리 관리 열기는 카테고리 아래 작은 글자
- 인기순은 좋아요 많은 순, 같으면 최신순(D-89). 공지는 늘 최신순
- `GET /api/blogs/{slug}/posts?sort=popular`, 응답에 `sort`. 카테고리·정렬·페이지를 주소에 남겨 글을 읽고 뒤로 와도 그대로
- 테스트 `PostSortIntegrationTest`

## 오류 수정

- **치지직 다시보기**가 글 안 재생기에서 "존재하지 않는 채널입니다"로 나오던 문제: 치지직에 다시보기 퍼가기 주소가 없어(`embed/vod`) 재생기 대신 "치지직 다시보기 · 치지직에서 보기 ↗" 카드(새 창)로 바꿈. 클립은 재생기 그대로 (021, D-127)
- **메인 "내 블로그"에서 글을 읽고 뒤로 가면 메인 피드로 바뀌던 문제**: 메인 피드의 블로그 목록이 화면을 열 때마다 주소를 `/?view=feed…`로 바꾸던 것을 고침. 이제 같은 블로그 단추·페이지·스크롤 위치로 돌아옴 (D-129)

## 보안

- 영상 썸네일은 서버가 받아 두므로 읽는 사람의 브라우저는 우리 서버 사진만 받음(보안 헤더 `img-src 'self'` 그대로)
- 썸네일을 받을 때(SSRF 대비): API 주소는 코드에 정한 것만, 사진 주소는 정한 사이트의 https(443)만, 다른 곳으로 넘기는 응답(redirect)은 따르지 않음, 연결 2초·응답 3초, 2MB까지. 받은 바이트는 앞부분으로 jpg·png·gif·webp인지 확인하고 위치 정보를 지움

## 운영·배포

- 0.16은 두 번 배포함: 처음(`f02ddcd`)은 목록·썸네일·정렬까지, 다시 배포(Deploy 수동 실행, `4f1b820`)에서 새 디자인·상단 글쓰기·공지 줄 위치까지
- 글꼴 파일: Jua 대신 Noto Serif KR 700(woff2 124개)

- Flyway V20이 시작할 때 `files`의 CHECK 제약을 바꿈
- 새 환경변수(선택): `VIDEO_THUMBNAIL_ENABLED`(기본 true). 서버가 바깥으로 요청을 보낼 수 없으면 false
- 결정 D-127: 글에 동영상 파일을 직접 올리는 기능은 만들지 않기로 함(6.3 "동영상 제외" 그대로)

## 알려진 제한

[0.15](v0.15.md#알려진-제한)에 더해:
- 치지직·SOOP 썸네일은 공식이 아닌 API라 사이트가 바꾸면 썸네일이 안 붙을 수 있음(배포 뒤 실제 링크로 확인 필요)
- 이미 쓴 글은 다시 저장해야 영상 썸네일이 붙음
- 치지직 다시보기는 글 안에서 재생되지 않고 카드로 치지직에 넘어감

## 블로그 공지 문구

관리자 화면의 공지 작성에 아래 제목과 본문을 붙여 넣습니다.

**제목**: One Blog 0.16 업데이트 안내

**본문**:

```markdown
안녕하세요, One Blog 운영팀입니다.

One Blog가 0.16으로 업데이트되었어요. 이번에 달라진 점을 알려 드려요.

- **새 디자인**: 글을 읽는 데 집중할 수 있도록 화면을 깔끔하게 새로 꾸몄어요. 제목은 명조체로, 바탕은 흰색으로 바뀌었어요.
- **어디서나 글쓰기**: 화면 위의 [글쓰기]를 누르면 바로 글을 쓸 수 있어요. 블로그가 여러 개라면 쓸 블로그를 고르면 돼요.
- **한눈에 보이는 글 목록**: 글 목록에서 글쓴이 사진, 본문 앞부분 두 줄, 좋아요·댓글 수를 함께 보여 드려요. 사진이 있는 글은 오른쪽에 크게 보여요.
- **영상 글에도 썸네일**: 유튜브·치지직·SOOP 영상 링크로 시작하는 글은 목록에 영상 썸네일이 붙어요. 이미 쓴 글은 한 번 다시 저장하면 붙어요.
- **카테고리마다 인기순**: 블로그에서 카테고리를 고른 뒤 오른쪽의 "인기순"을 누르면 좋아요가 많은 글부터 볼 수 있어요.
- **뒤로 가기 개선**: 메인 "내 블로그"에서 글을 읽고 뒤로 오면 보던 자리 그대로 돌아와요. 블로그에서 고른 카테고리와 정렬도 그대로예요.
- **치지직 다시보기**: 치지직 다시보기 링크는 글 안에서 "치지직에서 보기" 카드로 보여요. 누르면 치지직에서 바로 볼 수 있어요. (클립은 글 안에서 바로 재생돼요.)

앞으로도 편하게 쓰실 수 있도록 계속 다듬어 갈게요. 감사합니다.
```
