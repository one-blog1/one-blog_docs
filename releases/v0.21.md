## 기능·화면

**SNS 공유** (031, D-142)
- 글 아래 링크 복사 아이콘이 **공유** 아이콘으로 바뀌었습니다. 누르면 공유 창이 뜹니다.
  - 위: 글 주소 칸과 **복사** 버튼. 자동 복사가 막힌 브라우저(인앱 브라우저 등)에서는 창을 닫지 않고 주소를 선택해 두고 직접 복사하도록 안내합니다.
  - 아래: **X · 텔레그램 · 페이스북 · 기기 공유** 아이콘. SNS는 각 서비스의 공유 화면을 새 창으로 엽니다. 기기 공유는 휴대폰처럼 공유 창을 지원하는 기기에서만 보이고, 인스타그램 DM·문자 등으로 보낼 수 있습니다(인스타그램은 웹 공유 화면이 없어 이것으로 대신).
- 블로그 공개 범위에 따라 보이는 항목이 다릅니다(서버가 정함): 공개는 모두, 일부 공개는 주소 복사(key 포함)·기기 공유만, 비공개·숨긴 블로그·숨긴 글은 주소 복사만.
- 공유 미리보기는 이미 있던 Open Graph 태그(D-59·D-66)를 그대로 씁니다. 공유 수는 세지 않습니다(6.2).
- 외부 스크립트·앱 키를 쓰지 않아 보안 헤더(CSP)는 그대로입니다.

## 오류 수정

- 04:00 배치: 운영의 앱 2개가 동시에 배치를 시작할 때 한쪽이 금방 끝내고 잠금을 풀면 다른 쪽이 같은 날 한 번 더 돌 수 있던 문제를 고쳤습니다. 시작 뒤 5분까지 잠금을 유지하고, 잠금 주인 이름을 앱마다 다르게 합니다 (029, SCL-03).
- SonarQube가 찾은 버그 24개를 고쳤습니다(관리자 목록 개수 조회 null 방어, 배치 결과 null 방어, 파일 없음 처리, 트랜잭션 self-call 등). 사용자가 보는 동작은 바뀌지 않습니다 (030, D-141).

## 알려진 제한

[0.20](v0.20.md#알려진-제한) 그대로입니다. 더해:
