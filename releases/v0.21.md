# One Blog 0.21

메인 공지를 고치고 종류별로 골라 볼 수 있게 하고, 메인 공지 줄을 하나씩 넘겨 보여 주도록 바꾼 버전입니다 (2026-10-12). 새 버전 번호 규칙(D-121)의 첫 버전입니다. 화면 코드 정리(리팩터)도 함께 들어갔습니다.

- 코드: [one-blog1/one_blog](https://github.com/one-blog1/one_blog) 태그 `v0.21`
- 요구사항 기준: BRD-10, 결정 D-122, 기능 명세 018(메인 공지 개선)
- DB: Crowfoot ERD "One Blog 메인블로그" v11, 마이그레이션 `V18__add_post_notice_category.sql`

## 기능·화면

**공지 수정** (018, BRD-10)
- 관리자 화면 공지 탭에 [수정] 단추를 [삭제] 왼쪽에 둠. 누르면 위 작성 칸에 종류·제목·내용 원문이 채워지고 "수정 저장"·[취소]로 바뀜
- `PUT /api/admin/notices/{id}`, 수정 칸용 원문 `GET /api/admin/notices/{id}`. 활동 기록 `NOTICE_UPDATE`(ADM-06)
- 고쳐도 알림은 다시 보내지 않음. 고친 공지는 내용 화면에 "수정됨 · 고친 시각"

**공지 종류** (D-122)
- 일반·업데이트·수정·점검. `posts.notice_category`(메인 공지만 값), 기존 공지는 일반으로 채움
- 작성·수정 칸에서 고르고, 목록·내용·메인 공지 줄에 이름표. 점검은 붉은 글씨

**공지 목록** (`/notice.html`)
- 주소에 공지 번호가 없으면 목록: [전체/일반/업데이트/수정/점검] 탭, 최신순, 페이지
- 내용 화면의 "목록으로"는 보던 종류·페이지로 돌아감. `GET /api/notices?category=UPDATE`
- 관리자 공지 탭의 제목도 내용 화면 링크

**메인 공지 줄**
- 최근 3개를 가로로 나열하던 것을, 최신 5개를 한 줄에 하나씩 2초마다 넘기도록 바꿈 ("1 / 5" 위치 표시, "전체 보기")
- 마우스를 올리거나 키보드로 들어가면 멈춤. 움직임 줄이기 설정이면 효과 없이 글자만 바뀜. 화면 읽기 프로그램에 2초마다 읽어 주지 않음

## 오류 수정

- 관리자 화면에서 숨김·삭제·공지 작성 뒤 "처리했습니다" 같은 안내가 목록을 다시 불러오면서 바로 지워지던 문제

## 코드 정리 (기능 변화 없음)

- 화면 스크립트를 `js/lib`(공통)·`js/components`(부품)·`js/pages`(화면별)로 나눔
- 날짜 표시·글 주소·입력칸 오류 글을 `js/lib/ui.js` 하나로 모음 (여러 파일의 중복 제거)
- `app.css`를 화면 순서대로 재배치하고 같은 선택자를 두 번 정의한 9곳을 합침. 21개 화면의 전후 스타일이 같음을 브라우저로 확인
- 화면 코드 위치 규칙을 코드 저장소 `readme.md`·`CLAUDE.md`에 적음

## 블로그 공지 문구

관리자 화면의 공지 작성에서 종류를 **업데이트**로 고르고 아래 제목과 본문을 붙여 넣습니다.

**제목**: One Blog 0.21 업데이트 안내

**본문**:

```markdown
안녕하세요, One Blog 운영팀입니다.

One Blog가 0.21로 업데이트되었어요. 이번에 달라진 점을 알려 드려요.

- **공지를 종류별로**: 공지마다 일반·업데이트·수정·점검 이름표가 붙어요. 공지사항 화면에서 원하는 종류만 골라 볼 수 있어요.
- **공지 모아 보기**: 메인 화면 공지 줄의 "전체 보기"를 누르면 지금까지의 공지를 한곳에서 볼 수 있어요.
- **한눈에 보는 공지 줄**: 메인 화면 위 공지가 한 줄에 하나씩 차례로 넘어가요. 마우스를 올리면 잠시 멈춰요.

앞으로도 편하게 쓰실 수 있도록 계속 다듬어 갈게요. 감사합니다.
```
