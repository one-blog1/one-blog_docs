# One Blog 0.13

화면을 옮길 때마다 글꼴과 CSS·JS를 다시 받던 문제를 고쳐 화면이 빨리 뜨게 하고, 사이트 아이콘을 넣은 버전입니다 (2026-10-12). 버전 번호를 0.01씩 올리는 규칙(D-121)으로 이전 버전 이름을 0.10~0.12로 바꾼 뒤 처음 배포한 버전입니다.

- 코드: [one-blog1/one_blog](https://github.com/one-blog1/one_blog) 태그 `v0.13`
- 요구사항 기준: 4.2 성능, 결정 D-121

## 기능·화면

- 브라우저 탭과 즐겨찾기에 사이트 아이콘(흰 바탕에 검은 "원") 표시

## 성능

- 정적 파일 브라우저 캐시 (`common/config/WebConfig.java`). 이전에는 Spring Security 기본값 때문에 모든 응답이 `Cache-Control: no-store`라서, 화면마다 한글 글꼴 조각(Jua·IBM Plex Sans KR, 275개 중 그 화면 글자에 필요한 수십 개)과 CSS·JS를 처음부터 다시 받았음
  - 글꼴 `/fonts/**`: 1년, `immutable` (다시 묻지 않음)
  - `/css/**`, `/js/**`, `/images/**`: `no-cache` (저장하되 매번 바뀌었는지만 확인, 안 바뀌었으면 304). 배포하면 바로 새 화면이 보임
  - 업로드 이미지 `/files/`는 그대로 1일
- 테스트 `StaticCacheIntegrationTest`

## 운영·배포

- 버전 번호 규칙 D-121: 배포마다 0.01씩. 이전 0.1.0·0.2.0·0.21을 0.10·0.11·0.12로 이름을 바꿈 ([releases/README.md](README.md))

## 알려진 제한

[0.12](v0.12.md#알려진-제한)와 같습니다. 화면이 여전히 느리면 다음은 API 응답 시간과 DB(Crowfoot)까지의 왕복 시간을 재 볼 차례입니다.
