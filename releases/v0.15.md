# One Blog 0.15

글에 붙인 영상 링크를 글 안에서 재생하고, 카카오·네이버·구글 계정으로 가입·로그인할 수 있게 한 버전입니다 (2026-10-12).

- 코드: [one-blog1/one_blog](https://github.com/one-blog1/one_blog) 태그 `v0.15`
- 요구사항 기준: BRD-01, USR-09(새로 정함), USR-01·02·05·06·07, SEC-04, SEC-06, SEC-12, SCL-01, 4.6, 결정 D-125·D-126, 기능 명세 021(글 안 영상 재생), 022(소셜 로그인)

## 기능·화면

**글 안 영상 재생** (021, D-125)
- 글 본문에 한 줄로 붙인 영상 링크를 글 폭에 맞춘 16:9 재생기로 바꿈
- 유튜브(watch·youtu.be·shorts·live → youtube-nocookie), 치지직(클립·다시보기), SOOP(다시보기, 예전 도메인 포함)만
- 서버가 링크에서 영상 번호만 뽑아 iframe(sandbox, loading=lazy)을 만듦. 글쓴이가 직접 쓴 iframe은 계속 지움. 문장 중간의 링크·글자가 다른 링크는 그대로 링크
- 테스트 `VideoEmbedTest`, `VideoFrameCspTest`

**소셜 로그인** (022, USR-09, D-126)
- 로그인·가입 화면에 "카카오로 로그인" 등 단추. 키(Secrets)가 들어온 사이트만 보임
- 처음이면 소셜 가입 화면: 이메일(구글처럼 사이트가 인증한 것만 그대로, 아니면 인증번호), 이름·닉네임(사이트 값으로 채움)·휴대전화·약관 동의 → 가입하고 바로 로그인. 비밀번호는 만들지 않음
- 같은 이메일의 기존 회원에 저절로 붙이지 않음. 가입 화면 아래에서 비밀번호로 로그인하면 연결
- 내 정보 > 소셜 로그인에서 사이트별 연결하기·연결 끊기
- 비밀번호 없는 회원: 마지막 연결은 끊을 수 없고, 프로필 수정 전 재확인·탈퇴는 비밀번호 찾기로 먼저 비밀번호를 만들게 함(PASSWORD_NOT_SET). 탈퇴하면 연결 삭제
- 새 테이블 `social_accounts` (ERD v18, V19). `js/pages/account.js`를 `js/pages/account/`로 옮김
- 테스트 `SocialLoginIntegrationTest`, `SocialProfilesTest`

## 보안

- 재생기 사이트 세 곳만 보안 헤더 frame-src에 더함
- 소셜 로그인은 세션 없이 서명한 HttpOnly 쿠키(state·가입 대기·연결 표시, 10~15분)를 쓰고, 사이트의 액세스 토큰은 저장하지 않음. 가입 대기·연결 표시 값은 로그인 쿠키로 쓸 수 없음
- 내 정보의 연결하기는 CSRF 검사를 거친 요청에서만 연결 표시를 만들어, 다른 사이트가 남의 계정에 소셜 계정을 붙일 수 없음

## 운영·배포

- 새 Secrets(선택): `KAKAO_CLIENT_ID`·`KAKAO_CLIENT_SECRET`, `NAVER_CLIENT_ID`·`NAVER_CLIENT_SECRET`, `GOOGLE_CLIENT_ID`·`GOOGLE_CLIENT_SECRET`
- `PUBLIC_BASE_URL`이 비어 있으면 `https://one-blog.java21.net`을 씀. 각 사이트에 등록할 돌아오는 주소는 `https://one-blog.java21.net/login/oauth2/code/{kakao|naver|google}`
- 개인정보 처리방침에 소셜 로그인 항목·보관 기간·쿠키, 외부 영상 재생 안내를 더함

## 알려진 제한

[0.14](v0.14.md#알려진-제한)에 더해:
- 카카오는 비즈 앱이 아니라 이메일을 받지 못해 가입 때 이메일 인증번호를 한 번 더 받음
- 네이버 앱이 "개발 중"이면 등록한 멤버만 로그인할 수 있음(검수 뒤 모두)
- 구글은 키를 등록하기 전까지 꺼져 있음
- 소셜 로그인은 "로그인 유지"를 체크하지 않은 것과 같음

```markdown

- **카카오·네이버로 시작하기**: 로그인 화면에서 카카오나 네이버 계정으로 가입하고 로그인할 수 있어요. 이미 회원이라면 내 정보 > 소셜 로그인에서 연결해 두면 다음부터 버튼 하나로 로그인돼요.
- **보안 강화**: 로그인과 글 화면의 보안을 강화했어요.

앞으로도 편하게 쓰실 수 있도록 계속 다듬어 갈게요. 감사합니다.
```
