# One Blog 0.11

개인정보 처리방침과 이용약관을 공개하고, 가입할 때 두 필수 동의를 확실히 받도록 바꾼 버전입니다 (2026-10-12). 같은 날 운영 서버의 HTTPS·사람 확인·쿠키 보안 설정도 켰습니다.

- 코드: [one-blog1/one_blog](https://github.com/one-blog1/one_blog) 태그 `v0.11` (처음 붙인 이름 `v0.2.0`, D-121로 바꿈)
- 요구사항 기준: 4장 4.6 개인정보 처리, USR-01, 기능 명세 [017](../specs/017-policy-pages/spec.md)

## 기능·화면

**개인정보 처리방침·이용약관** (017)
- `privacy.html`: 개인정보보호위원회 작성지침 순서의 12개 항목 (처리 목적·항목·보유 기간·파기·제3자 제공·위탁과 국외 이전(Google 메일 발송, Cloudflare 사람 확인)·정보주체 권리·안전성 조치·쿠키·보호책임자·구제 방법·변경)
- `terms.html`: 이용약관 12조와 부칙 (금지 행위, 게시물 권리, 이용 제한은 3.7 제재 권한·BLG-11~13·ADM-07과 같게)
- 모든 화면 맨 아래에 "이용약관 · 개인정보 처리방침" 링크 (`header.js`가 한 번에 붙임, 처리방침은 굵게)

**가입 동의** (017, USR-01)
- 가입 ③단계에 "전체 동의" 추가, 각 항목 아래에 전문을 작은 스크롤 상자로 표시하고 "새 창으로" 링크
- 두 필수 항목에 모두 동의하기 전에는 "가입하기" 버튼이 눌리지 않음 (서버도 기존처럼 400으로 거부)

## 보안

- 처리방침·약관 화면을 비회원 허용 목록에 추가 (`SecurityConfig`). 전문은 `innerHTML` 대신 DOMParser로 옮겨 넣음 (SEC-06 규칙 유지)
- 운영 설정 (코드 변경 없음, 2026-10-12 적용): nginx에 HTTPS(Certbot)와 http→https 301, 로그인 쿠키 `Secure`(`COOKIE_SECURE=true`), 로그인 3번 실패 후 Cloudflare Turnstile(SEC-13). 자세한 현황은 [보안 진행 현황](../docs/security-status.md)

## 운영·배포

- GitHub Actions의 Action 버전을 Node 24용으로 올림 (Node 20 지원 종료 경고 해소)
- 테스트 추가: `PolicyPagesIntegrationTest`, `SignupIntegrationTest`(이용약관 미동의 400)

## 알려진 제한

[0.10](v0.10.md#알려진-제한)에서 HTTPS와 쿠키 Secure는 해결됐습니다. 남은 것:

- 같은 IP 로그인 제한이 nginx 뒤에서 모든 요청을 127.0.0.1로 봐서 사이트 전체에 하나로 걸립니다 (`FORWARD_HEADERS_STRATEGY` 설정 전). HSTS 헤더도 같은 이유로 빠져 있습니다.
- 앱 포트 8430이 서버에서 직접 열려 있습니다 (`SERVER_ADDRESS` 설정 전).
- 개발(로컬)과 운영 서버가 같은 DB를 쓰는지 확인이 필요합니다.
- 공지는 쓰기·삭제만 되고 수정은 안 됩니다.
- 처리방침·약관은 공개 전 법률 검토를 받지 않았습니다 (4.6).
