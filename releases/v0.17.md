## 기능·화면

**메인 배너** (025, D-132, D-133)
- 메인 "내 블로그"·"메인 피드" 탭 맨 위에 큰 사진 배너(PC 380px, 휴대폰 220px). 5초마다 다음 장, 마우스·키보드가 올라가면 멈춤, 멈춤·이전·다음·점 단추. 기기의 "움직임 줄이기"가 켜져 있으면 자동으로 넘기지 않음. "참여 신청" 탭과 보여 줄 것이 없을 때는 숨김
- 자동: 인기 글(최근 7일, 썸네일 있는 글을 좋아요 → 조회수 → 최신 순으로 3개), 새 블로그(최근 30일에 만든 공개 블로그 2개), 인기 블로그(최근 30일 새 멤버가 많은 공개 블로그 2개, 새 블로그와 겹치면 뺌). 메인 피드 인기 글과 같은 범위(차단한 회원 글 제외)
- 관리자: 광고·공지·이벤트 중 종류를 골라 사진·제목·작은 글씨·링크를 넣음. 노출을 켠 것 중 순서대로 8개. 종류 이름을 늘 표시(광고만 초록), 바깥 주소는 새 창(광고는 `rel="sponsored"`)
- 종류를 하나씩 번갈아 놓음: 인기 글 → 관리자 배너 → 새 블로그 → 인기 블로그 → …
- 사진이 없거나 불러오지 못하면 그 블로그 색과 첫 글자(관리자 배너는 어두운 바탕)
- 메인 피드 맨 위 인사말("오늘은 어떤 이야기를 읽어 볼까요?")은 뺌
- `GET /api/banners`(누구나)

**관리자 화면 "배너" 탭** (ADM-08)
- 자동 종류마다 개수(0~5, 0이면 끔)·기간(1·7·30일), 지금 나갈 배너 미리보기. 고른 개수보다 적게 나가면 이유("조건에 맞는 것이 n개")를 보여 줌
- 광고·공지·이벤트 추가·수정·삭제·보이기/숨기기·위아래 순서. 사진은 jpg·png·gif·webp 3MB까지
- 모든 조치는 활동 기록(`BANNER_CREATE`·`UPDATE`·`MOVE`·`DELETE`·`SETTINGS`)
- `/api/admin/banners`, `/api/admin/banners/image`, `/api/admin/banners/{id}/move`, `/api/admin/banner-settings`

**배너 미리보기·사진 위치** (026, D-134, 같은 0.17로 다시 배포)
- 관리자 배너 추가·수정 칸에 실제 배너와 같은 미리보기(PC·휴대폰), 종류·제목·작은 글씨를 적는 대로 반영
- 사진을 끌거나 가로·세로 막대(0~100%)로 보일 자리를 정하고 [가운데로]. 배너마다 저장해 메인 배너에 적용 (`banners.image_pos_x·image_pos_y`, ERD v28, V23)

**내 블로그 목록 작게** (D-132)
- "내 블로그" 탭: 배너 → 내 블로그 목록(그림 60px, 이름 한 줄, 맨 끝 "+ 만들기", 많으면 옆으로 밀기) → 새 글

## 오류 수정

- **신고 창**에 테두리가 없고 접수 알림에 [확인] 단추가 없던 문제: 다른 창과 같은 가운데 창(제목·닫기·테두리·여백)으로, 접수되면 [확인]이 있는 알림 창 (SOC-06, D-112)
- **영상 썸네일**이 붙지 않던 경우 (024, D-128)
  - 이름 붙인 링크(`[영상](주소)`)와 문장 속 영상 주소도 첫 영상으로 셈
  - 기능 이전에 쓴 글은 서버가 뜬 뒤 한 번 채움(최근 글부터 500개). 다시 저장하지 않아도 됨
  - 영상 사이트 응답을 Content-Type과 관계없이 JSON으로 읽고, 사진이 다른 주소로 넘기면 허용한 사이트 안에서 3번까지 따라감. 받지 못한 이유를 서버 로그에 남김

## 보안

- 배너 링크는 서버가 검사: `https://`·`http://`(호스트 필수, 사용자 정보 금지) 또는 `/`로 시작하는 우리 주소만. `javascript:`·`//다른 사이트` 등은 거부. 화면도 한 번 더 확인
- 배너 사진은 우리 서버 `/files/`만(보안 헤더 `img-src 'self'` 그대로), 관리자만 올림(파일 형식·크기 검사, 위치 정보 제거)

**본문**:

```markdown
안녕하세요, One Blog 운영팀입니다.

One Blog가 0.17로 업데이트되었어요. 이번에 달라진 점을 알려 드려요.

- **메인 배너**: 메인 "내 블로그"와 "메인 피드" 맨 위에 큰 사진 배너가 생겼어요. 이번 주 인기 글, 새로 생긴 블로그, 요즘 사람이 모이는 블로그, 공지와 이벤트를 5초마다 넘겨 보여 드려요. 마우스를 올리거나 멈춤 단추를 누르면 멈춰요.
- **더 간단해진 내 블로그 목록**: "내 블로그" 탭의 블로그 목록을 작은 그림과 이름으로 줄여 새 글을 더 빨리 볼 수 있어요.
- **영상 썸네일 개선**: 글 중간에 넣은 영상 링크나 이름을 붙인 영상 링크도 목록에 썸네일이 붙어요. 예전에 쓴 글도 다시 저장하지 않아도 썸네일이 붙어요.
- **신고 창 개선**: 신고 창을 보기 쉽게 다듬었고, 신고가 접수되면 확인 창으로 알려 드려요.

앞으로도 편하게 쓰실 수 있도록 계속 다듬어 갈게요. 감사합니다.
```
