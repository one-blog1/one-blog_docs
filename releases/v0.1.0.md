# One Blog 0.1.0

첫 배포 버전입니다 (2026-10-08). 회원이 블로그를 만들고 함께 운영하는 블로그 커뮤니티의 기본 기능을 모두 담았습니다.

- 코드: [one-blog1/one_blog](https://github.com/one-blog1/one_blog) 커밋 `0488c60`
- 요구사항 기준: 8장 결정 기록 D-01 ~ D-118, 기능 명세 001 ~ 016

## 기능

**회원·계정** (001, 015, 016)
- 이메일 인증번호(6자리)로 회원가입, 로그인·로그아웃, 로그인 유지
- 로그인 5번 실패 시 잠금, 비밀번호 찾기·이메일 찾기
- 내 정보: 이메일·이름·전화번호는 가려서 보여 주고, 비밀번호를 다시 확인한 뒤 수정
- 설정: 알림 종류, 프로필 공개 범위, 차단한 회원, 화면(밝게·어둡게·기기 설정, 글자 크기)
- 회원 탈퇴 (쓴 글은 "탈퇴한 회원"으로 남음)

**블로그** (002, 003, 012)
- 블로그 만들기: 공개·일부 공개·비공개, 회원당 개수 제한
- 참여 방식(자유·승인제)과 참여 신청·승인·취소
- 메인 첫 화면: 내 블로그(참여 중인 블로그와 새 글), 메인 피드, 참여 신청 탭
- 블로그 운영: 정보 수정, 부블로그장과 권한, 멤버 관리(글·댓글·경고 수 보기, 내보내기), 탈퇴·위임·폐쇄 예약(매일 04:00 처리)

**글·댓글** (004, 005, 006, 008, 014)
- 마크다운 에디터로 글 쓰기·고치기·지우기, 블로그 공지
- 이미지 첨부(3MB 이하, 위치 정보 제거), 글 목록 오른쪽 사진 미리보기
- 카테고리·태그, 조회수, SNS 공유 미리보기
- 댓글·답글(@닉네임), 좋아요, 알림에서 댓글 위치로 바로 가서 강조

**소셜·검색·알림** (009, 010, 011)
- 회원 팔로우, 블로그 구독, 프로필 화면 (닉네임을 누르면 프로필로)
- 상단 검색창: 블로그·글·태그·닉네임, 최근 검색어
- 알림 종: 알림 상세와 바로가기, 바깥을 누르면 닫힘

**관리·제재** (007, 013)
- 관리자 화면: 회원·글·댓글 처리와 해당 위치로 바로가기, 메인 공지, 통계, 처리 기록
- 관리자는 비공개 글·숨긴 블로그까지 열람 (열람 기록 남김)
- 블로그별 차단·제재·블랙리스트, 신고와 관리자 처리

## 보안

- 로그인: JWT + HttpOnly 쿠키, Refresh Token은 DB에 해시로 저장
- CSRF 토큰, 보안 헤더(CSP, X-Frame-Options, nosniff, Referrer-Policy)
- 비밀번호 bcrypt, 인증번호·블랙리스트는 서버 비밀값을 섞은 HMAC으로 저장
- 글 본문은 서버에서 위험한 HTML을 걸러서 보냄, 요청 제한

## 운영·배포

- main에 push·merge → CI(전체 테스트, jar·Docker 실행 확인) → 성공하면 서버에 Docker로 자동 배포 (포트 8430)
- 새 버전이 상태 확인(`/api/health`)을 통과하지 못하면 바로 전 버전으로 자동 되돌림
- 서버와 DB 시간대를 한국 시간으로 고정
- 실제 인증 메일 발송 (Gmail SMTP)

## 알려진 제한

- HTTPS가 아직 없어 http로만 접속합니다. 로그인 쿠키의 Secure 설정은 꺼 둔 상태입니다.
- 개발(로컬)과 운영 서버가 같은 DB를 씁니다. 로컬에서 바꾼 데이터가 운영에도 보입니다.
- 업로드 사진은 서버 디스크(Docker 볼륨)에 따로 저장됩니다. 로컬에서 올린 사진은 서버로 복사해야 보입니다.
- 내부망 서버라 바깥에서 접속하려면 포트 개방이 필요합니다.
- 공지는 쓰기·삭제만 되고 수정은 안 됩니다.

## 블로그 공지 문구

관리자 화면의 공지 작성에 아래 제목과 본문을 붙여 넣습니다.

**제목**: One Blog 0.1.0 오픈 안내

**본문**:

```markdown
안녕하세요, One Blog 운영팀입니다.

One Blog가 0.1.0 버전으로 문을 열었습니다. 지금 바로 이런 것들을 할 수 있어요.

- **나만의 블로그 만들기**: 공개·일부 공개·비공개 중에 고를 수 있어요.
- **함께 운영하기**: 다른 회원의 블로그에 참여 신청을 하고, 내 블로그에 멤버를 모아 함께 글을 쓸 수 있어요.
- **글과 사진**: 마크다운 에디터로 글을 쓰고 사진을 붙일 수 있어요. 카테고리와 태그로 정리해 보세요.
- **소통하기**: 댓글과 답글, 좋아요로 이야기를 나누고, 마음에 드는 회원은 팔로우, 블로그는 구독할 수 있어요.
- **알림과 검색**: 새 소식은 오른쪽 위 알림 종에서, 원하는 글과 블로그는 위쪽 검색창에서 찾을 수 있어요.
- **내 화면 꾸미기**: 설정에서 어두운 화면과 큰 글자를 고를 수 있어요.

아직 첫 버전이라 부족한 점이 있을 수 있어요. 불편한 점이나 오류는 언제든 알려 주세요. 앞으로 버전을 올릴 때마다 이 공지사항에서 바뀐 점을 알려 드릴게요.

감사합니다.
```
