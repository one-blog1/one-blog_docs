# Feature Specification: 배너 미리보기와 사진 위치 정하기

**Feature Branch**: `main` | **Created**: 2026-10-13 | **Status**: Implemented

**Input**: "배너에 이미지 넣을 때 어떻게 보이는지 미리 알고 보이는 위치 조정할 수 있는 기능"

**관련 요구사항**: ADM-08, BRD-12, 6.8, D-132, D-133, D-134

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 미리보기 (Priority: P1)

1. 관리자 "배너" 탭의 추가·수정 칸에 메인 배너와 같은 모양의 미리보기 두 개: PC(1080×380을 줄임), 휴대폰(358×220).
2. 종류·제목·작은 글씨를 적으면 미리보기가 바로 바뀐다. 사진을 올리면 바로 보인다.

### User Story 2 - 사진 위치 (Priority: P1)

1. 미리보기 사진을 끌면 보일 자리가 움직인다(오른쪽으로 끌면 왼쪽 부분이 더 보임). 넘치는 방향으로만 움직인다.
2. 가로·세로 막대(0~100%)로도 정하고, [가운데로]로 50%·50%로 되돌린다.
3. 저장하면 배너마다 남고(banners.image_pos_x·image_pos_y), 메인 배너가 그 자리로 보여 준다. 새 사진은 가운데부터.
4. 0~100 밖이면 거부. 빼면 가운데. 노출 켜기·끄기만 바꿀 때도 위치는 그대로.

### Edge Cases

- 자동 배너(인기 글·새 블로그·인기 블로그)는 가운데.
- 사진이 없으면 막대를 숨기고 "사진을 골라 주세요".
