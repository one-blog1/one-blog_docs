# Feature Specification: 메인 배너 (인기 글·광고), 관리자 배너 관리, 내 블로그 목록 작게

**Feature Branch**: `main` | **Created**: 2026-10-13 | **Status**: Implemented

**Input**: "메인 피드랑 내 블로그 탭에 자동으로 시간되면 넘어가게 해서 이미지 크게 하고 광고 글 이런거 하고 싶은데", 시안 "배너 A"·"2안" 선택, "인사말 빼고 배너 글은 광고의 경우 관리자가 직접, 인기 글 같은 경우는 썸네일이랑 제목 자동으로, 관리자 화면에 해당 기능도 추가해줘"

**관련 요구사항**: BRD-12, ADM-08, ADM-06, BRD-09, 6.3, 6.8, D-89, D-128, D-132, D-133

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 메인 배너 보기 (Priority: P1)

1. 메인 "메인 피드" 탭 맨 위(예전 인사말 자리)와 "내 블로그" 탭 맨 위에 높이 380px(휴대폰 220px) 큰 사진 배너. 사진 아래쪽 어두운 띠에 표시("이번 주 인기"·"광고")·제목·작은 글씨.
2. 5초마다 다음 장. 마우스·키보드가 배너 안에 있으면 멈춤. 멈춤·이전·다음·점 단추와 "1 / 4". 움직임 줄이기 설정이면 자동으로 넘기지 않음.
3. 인기 글을 누르면 그 글, 광고를 누르면 광고 링크(바깥 주소는 새 창).
4. 보여 줄 것이 없으면 배너 자리를 숨긴다. 참여 신청 탭에는 없다.

### User Story 2 - 인기 글 자동 (Priority: P1)

1. 최근 N일(기본 7) 글 중 메인 피드 인기 글과 같은 범위(전체 공개 블로그의 공개 글, 차단한 회원 글 제외), 좋아요 1개 이상, 썸네일 있는 글을 좋아요 많은 순(같으면 최신)으로 M개(기본 3).
2. 사진 = 글 썸네일, 제목 = 글 제목, 작은 글씨 = 블로그 이름 · 좋아요 N.

### User Story 3 - 광고 관리 (Priority: P1)

1. 관리자 화면 "배너" 탭: 광고 추가(사진·제목·작은 글씨·링크·노출), 목록에서 수정·삭제·노출 켜고 끄기·위아래 순서.
2. 링크는 `https://`·`http://` 또는 `/`로 시작(`//` 제외). 노출 켠 광고 중 순서대로 5개까지 나간다.
3. 사진을 바꾸거나 광고를 지우면 예전 사진은 지운 것으로 표시(30일 뒤 삭제). 저장하지 않은 업로드 사진도 30일 뒤 지운다.
4. 모든 조치는 활동 기록에 남는다.

### User Story 4 - 인기 글 설정 (Priority: P2)

1. 관리자 화면 "배너" 탭: 인기 글 수(끔, 1~5)와 기간(오늘·7일·30일)을 바꾸고, 지금 나갈 인기 글을 미리 본다.

### User Story 5 - 내 블로그 목록 작게 (Priority: P1)

1. "내 블로그" 탭: 배너 → "내 블로그" 제목·"내 블로그 관리" → 60px 그림 + 이름 한 줄 + "+ 만들기" → 새 글. 많으면 옆으로 밀어 본다.

### User Story 6 - 배너 종류 늘리기 (Priority: P1, D-133)

Input: "목록 다양화 하고싶은데", "새 블로그 인기 블로그는 인기 글처럼 자동으로 등록(관리자 화면에서 개수, 기간 조절 가능), 공지, 이벤트는 관리자 페이지에서 광고와 양식 똑같이 해서 광고, 공지, 이벤트를 목록에서 선택할 수 있게", "인기글 여러 개로 늘려도 1개만 나가는데"

1. 자동: 새 블로그(최근 N일에 만든 공개 블로그, 최신순), 인기 블로그(최근 N일 새 멤버가 많은 공개 블로그). 종류마다 개수 0~5·기간 1·7·30일. 대표 이미지가 없으면 블로그 색과 첫 글자.
2. 관리자: 광고 칸에 종류(광고·공지·이벤트)를 고른다. 표시는 종류 이름, 노출 켠 것 8개까지.
3. 인기 글은 좋아요가 없어도 개수를 채운다(좋아요 → 조회수 → 최신). 고른 개수보다 적게 나가면 관리자 화면이 이유를 보여 준다.
4. 순서: 인기 글 → 관리자 배너 → 새 블로그 → 인기 블로그를 하나씩 번갈아.

### Edge Cases

- 관리자 계정이 메인에 오면 배너는 보이지만 내 블로그 탭은 그대로(관리자는 블로그 없음).
- 배너가 한 장이면 넘김 단추를 숨긴다.
