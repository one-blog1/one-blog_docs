# Feature Specification: 글 목록 새 모양·영상 썸네일, 블로그 글 최신순·인기순

**Feature Branch**: `main` | **Created**: 2026-10-13 | **Status**: Implemented

**Input**: "글 옆에 글의 이미지를 추가하고 싶은데 영상 썸네일 같은 것도"(네이버 블로그 목록 예시), "우리 블로그의 글 정렬 조건에 왜 최신순만 있지 인기순은 없어? … 각 카테고리마다 최신순, 인기순으로 볼 수 있도록", "내 블로그 탭의 글을 읽고 뒤로 가기를 누르면 메인 피드 탭으로 자동이동 되는 거 이상해"

**관련 요구사항**: BRD-02, 6.3, SEC-08, D-89, D-113, D-125, D-128, D-129

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 글 목록 새 모양 (Priority: P1)

1. 블로그·메인 "내 블로그의 새 글"·메인 피드·검색·태그 목록의 한 줄: 작성자 사진·닉네임·날짜, 굵은 제목, 본문 앞부분 2줄, 블로그 이름·카테고리와 좋아요·댓글·조회 수, 태그, 오른쪽 정사각형 썸네일(PC 120px, 휴대폰 88px).
2. 블로그 공지 줄은 예전처럼 제목과 정보 한 줄.
3. 읽은 글 표시(D-123)는 그대로(제목 회색, 사진 흐리게, "읽음").

### User Story 2 - 영상 썸네일 (Priority: P1)

1. 본문에서 처음 나오는 사진·영상 링크(한 줄짜리, D-125) 중 첫 번째가 영상이면, 글을 저장한 뒤 서버가 그 영상 썸네일을 한 번 받아 우리 서버에 두고 목록 썸네일과 og:image로 쓴다. 썸네일 왼쪽 아래에 "▶ YouTube"·"▶ 치지직"·"▶ SOOP".
2. 같은 영상으로 다시 저장하면 다시 받지 않는다. 영상이 바뀌거나 빠지거나 글을 지우면 예전 썸네일은 지운 것으로 표시(30일 뒤 삭제).
3. 받지 못하거나(사이트 오류·시간 초과·API 변경) 사진이 아니면 썸네일 없이 둔다. 글 저장은 실패하지 않는다.

### User Story 3 - 블로그 글 최신순·인기순 (Priority: P1)

1. 블로그 화면 카테고리 줄 오른쪽 끝에 작은 글자 "• 최신순 • 인기순"(고른 것은 빨간 점). 카테고리 관리 열기는 카테고리 줄 아래 작은 글자. 고른 카테고리(전체 포함) 안에서 정렬한다. 카테고리를 바꿔도 고른 정렬은 유지.
2. 인기순은 좋아요 많은 순, 같으면 최신순(D-89). 공지는 늘 최신순으로 위에.
3. 카테고리·정렬·페이지는 주소(`?category=&sort=popular&page=`)에 남아 글을 읽고 뒤로 와도 그대로. 공유 링크 key는 그대로 둔다.

### User Story 4 - 메인 "내 블로그"에서 뒤로 가기 (Priority: P1)

1. "내 블로그의 새 글"에서 글을 읽고 뒤로 오면 "내 블로그" 화면, 같은 블로그 단추·같은 페이지·같은 스크롤 위치.
2. 원인: 메인 피드의 블로그 목록이 화면을 열 때마다 주소를 `/?view=feed&…`로 바꿨다. 이제 그 목록을 직접 만졌거나 처음부터 메인 피드 주소로 열었을 때만 바꾼다.

### Edge Cases

- 다른 사이트 사진(`![](https://…)`)은 화면에 보이지 않으므로 첫 미디어로 세지 않는다.
- 문장 중간 링크·이름 붙인 링크는 영상이 아니다(D-125와 같음).
- 모르는 정렬 값은 최신순.
